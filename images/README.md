# Artiola photos

Put real photos from @artt_nailsss in this folder using these exact names.
The page picks them up automatically. If a file is missing, that spot keeps
the drawn nail set instead.

| File | Where it shows | Best shape |
|---|---|---|
| `hero.jpg` | Big photo at the top of the page | Landscape (5:4 or 4:3) |
| `profile.jpg` | Round profile picture in "Meet the artist" | Square |
| `look-1.jpg` | Cherry Glaze card + profile grid | Landscape (4:3) |
| `look-2.jpg` | Milky French card + profile grid | Landscape (4:3) |
| `look-3.jpg` | Lilac Chrome card + profile grid | Landscape (4:3) |
| `look-4.jpg` | Mocha Matte card + profile grid | Landscape (4:3) |
| `look-5.jpg` | Love Notes card + profile grid | Landscape (4:3) |
| `look-6.jpg` | Midnight Swirl card + profile grid | Landscape (4:3) |

Photos are cropped to fill their frame, so keep the nails near the centre.
Aim for about 1600px wide and under 400 KB each so the page stays fast.
